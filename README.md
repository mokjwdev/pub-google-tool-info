# Public information for personal Google tools

This repository contains shared public information pages for privately operated tools that use Google APIs.

The tools are intended for the owner and people who receive specific written permission. They are not offered as a public service.

Publishing these pages does not grant access to the tools, accounts, credentials, or data. The terms describe the owner's reserved rights and the conditions for permitted use.

See the [homepage](index.md), [privacy policy](privacy.md), and [terms of use](terms.md).
